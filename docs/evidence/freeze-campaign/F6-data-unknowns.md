## HYPOTHESES TESTED

- Upper input bits are known-reserved because DEFAULT.RPL uses only six bits: **not supported**. Source audit sees no use in the audited control path; the sole sample cannot distinguish reserved from future/other-path use. Keep bytes.
- `stunts_forged` contributes independent high-bit replay coverage: **false for the file corpus**. Its `DEFAULT.RPL` is hash-identical. Its 13 Port Forge replay-v2 recordings encode mouse/scancode events and are not a second `.RPL` corpus.
- The font's text bytes imply CP437/Unicode code points: **not supported**. Renderer uses the byte as table index; no source mapping found.
- HIG offset `0x10` is padding because the renderer skips it: **rejected as a semantic claim**. The source leaves it uninitialized on insertion and all 287 samples retain variable byte values. It can remain opaque, not “known padding.”
- VCE bytes after known game fields are all reserved: **falsified** by static driver reads into `+44..+46` and `+28`; retain full raw record and driver-specific interpretation.
- `.TD` exists because the game has a `trackdata` arena: **rejected**. No `.TD` file/reader evidence; keep file grammar unknown.
- Unknown physical unit labels imply the values can be omitted: **rejected** for active simulation values. Preserve types and reproduce integer equations; avoid guessed engineering conversions.
