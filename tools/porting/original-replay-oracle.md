# ArtifactV2 original-interpreter replay probe

`replay_oracle_probe.py` verifies a recorded ArtifactV2 prefix through the
matching PortForge **original DOS interpreter**, then saves its guest state and,
when in VGA mode 13h, its exact indexed framebuffer and six-bit DAC. It uses
the replay's declared base snapshot and canonical schema. It does not call the
native SDL3 port or use a generated reconstruction as the reference.

All source inputs under `--source-root` are read only. Put `--output-dir` under
an isolated `build/workers/NAME` directory. Existing output stems are refused.
For example:

```powershell
$source = 'D:/Games/DOS/dos_recosystem/stunts_forged'
$out = 'build/workers/replay_oracle/probe'
python tools/porting/replay_oracle_probe.py --source-root $source --output-dir $out --replay rec_20260820_204801 --to 800 --label countach --build-v13 --compiler C:/msys64/mingw64/bin/g++.exe
python tools/porting/replay_oracle_probe.py --source-root $source --output-dir $out --replay rec_20260827_013957 --to 800 --label lancia
```

The v13 runner is compiled from the preserved
`port_forge/build/history/pf-391f1dd` source, with its C++17/O2/Wall/Wextra/
Werror build flags, into the output directory. Later v13 probes should pass
`--v13-runner <that executable>`; a prebuilt matching runner may be provided
directly. V14 uses the reference checkout's `port_forge/build/pf_dos_session.exe`
by default, or an explicit `--v14-runner`.

`--to` counts semantic boundaries exclusively. A value of 800 captures guest
state after ordinal 799. The replay runner checks each named checkpoint within
the prefix against its recorded canonical digest, plus sparse audits. The
receipt reports the comparison count, mismatches, last recorded checkpoint,
last boundary stamp, interpreter and replay SHA-256, base declaration, program
SHA-256, guest CPU registers and instructions, and memory fingerprint. A
successful terminal state outside mode 13h produces a **state-only** receipt.
For mode 13h, the tool validates every sparse page and the complete 1 MiB
memory SHA-256 before saving 64,000 A0000 indices plus 768 DAC6 values as
`*.idxdac6`; it also writes a PNG preview. The preview is for inspection; the
indexed payload is the comparison authority.

The checked-in captures and reproduction commands are in
[`tests/fixtures/sdl3/original_replay/README.md`](../../tests/fixtures/sdl3/original_replay/README.md).
`pack_replay_oracle_fixture.py` converts a verified frame receipt to a compact
`.idxz` and provenance sidecar. The seven checked-in captures cover main menu,
Countach and Lancia selection, default track preview, clock opponent, driving,
and race results. Five come from unmodified corpus replays. The track and
opponent cases are controlled v14 menu branches generated by
`replay_menu_branch.py`: the source recording's input events before occurrence
450 are copied, with only the Drive mouse press/release at occurrences 264 and
270 moved to the target button. Each branch is itself an ArtifactV2 verified
by the original interpreter, with 21 canonical comparisons and zero mismatches
through boundary 800. Their fixture metadata labels this provenance and names
the source corpus recording.

Verified bounded coverage includes the v13 `rec_20260813_035233` replay through
boundary 9000 (16 canonical comparisons; menu, driving, results sampled), the
v13 `rec_20260820_204801` Countach screen through 800, the v14
`rec_20260827_013957` Lancia screen through 800, and both controlled branches
through 800. Full `rec_20260820_204801` [0,4954) passed nine canonical
comparisons and terminal digest
`e98ed3464dbf0f4801d9f9fd264f579112c93723272151fd6f57b8cadd1cf1c4`;
full v14 `rec_20260827_013930` [0,4670) passed nine and terminal digest
`6e04b7a42b0134389083268ac5f275e6901a0c50c898ee5006508543d2a93c07`.
The latter ended in DOS mode 3, so it has no final indexed frame. These are
bounded replay facts, not evidence that the native port has reached equivalent
state. Native full-frame tests must first align semantic state and input history
with the selected guest boundary.
