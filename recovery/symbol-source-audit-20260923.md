# Stunts symbol-source audit, 2026-09-23

The byte oracle is the supplied DOS 1.1 MCGA core. No original DOS MAP/SYM/debug artifact is present in `assets/` or the pinned local Restunts checkout. Absence from those trees does not prove none survives elsewhere. Restunts2's [analysis README](https://github.com/dstien/restunts2#analysis) lists the DOS MCGA executable without debug symbols and identifies two later i386 FM Towns `.exp` executables as shipped with debug symbols. It also describes a read-only Ghidra project for the DOS target. This pass did not retrieve an FM Towns executable or access that Ghidra server; no FM Towns name is treated as a verified DOS symbol here.

The pinned [Restunts checkout](../docs/current/provenance.md) contains `game_mod3.idb`, named `asmorig` disassembly, and reconstructed C. Names, structures and control-flow hints have mixed provenance and require pristine instruction/relocation checks. The [private forged cross-reference](forged-crossref.json) captures three geometry functions, but the source checkout and its private assets were absent at the checked local paths; the stored cross-reference is read-only evidence.

Concrete crosswalk: Restunts `src/restunts/asmorig/seg008.asm:3898-3973` names `shape3d_init_shape`; the importer had independently anchored its DOS load-image interval `[0x1955A,0x19606)`. A reviewed 69-instruction pristine decode now records the entire branchless CFG in `layout/function-evidence.json`. The Restunts C sequence supplied the assignment and structure hypothesis, but its 16-bit destination paint-count declaration conflicted with the pristine byte store. A first MSC 5.10 probe with a local far-pointer alias produced a 190-byte mismatch; direct far-argument reads produced an exact 172-byte contribution and passed whole-image promotion. See [experiment and receipts](experiments/shape3d-init-shape-20260923.md).

Next symbol work should seek an accessible export of the FM Towns symbol table and map a small set of shared algorithms through semantics, call neighbors and data layouts. Treat the later platform's names as hypotheses; accept DOS boundaries and bytes only from the pristine MCGA image. Meanwhile, source-backed Restunts functions with verified DOS intervals and no unsupported fixups remain a productive recovery path.
